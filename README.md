# MOTOX – Premium Motorcycle Showroom

GitHub Pages-ready static website built with HTML, CSS and JavaScript.

## Deployment

Upload the **contents of this folder** directly to the root of a GitHub repository. Do not upload this ZIP as the website root and do not put the files inside another folder.

The repository root must contain:

- `index.html`
- `css/style.css`
- `js/`
- `images/` (if present)

Then enable **Settings → Pages → Deploy from a branch → main → /(root)**.

## Important

- No login gate is used to block pages.
- All CSS and JavaScript paths are relative, so they work under a GitHub Pages project URL such as `/bike-web/`.
- Keep file and folder names exactly as provided because GitHub Pages is case-sensitive.
